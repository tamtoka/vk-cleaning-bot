# Учебный VK-бот каталога химчистки

Бот работает через VK Community Long Poll API и отвечает на входящие текстовые сообщения. Клавиатура обычная, с текстовыми кнопками. Каталог находится в `services.json`; цены учебные и демонстрационные.

## Требования

- Python 3.10 или новее. Установленная для разработки версия `vkbottle==4.11.0` указывает в метаданных `Requires-Python: >=3.10,<4.0`; проект проверен на Python 3.12.
- Сообщество VK с включёнными сообщениями и Long Poll.
- Ключ доступа сообщества с минимальным разрешением для работы с сообщениями (`messages`). Не выдавайте боту права управления сообществом, если они не нужны для других задач.
- Для Long Poll включите получение входящих сообщений (`message_new`). Названия настроек сверяйте с актуальным интерфейсом и документацией VK.

Актуальная документация: [vkbottle](https://vkbottle.readthedocs.io/ru/latest/) и [VK Bots Long Poll](https://dev.vk.com/ru/api/bots-long-poll/getting-started). В текущей среде эти сайты недоступны через сетевой прокси, поэтому перед реальным подключением сверьте права ключа и имя события с документацией VK.

## Настройка и запуск в Windows PowerShell

Перейдите в папку проекта и выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` в редакторе и задайте значения локально:

```dotenv
VK_TOKEN=вставьте_ключ_сообщества_локально
MANAGER_CONTACT=@имя_или_ссылка_на_менеджера
```

Не отправляйте ключ в чат и не добавляйте `.env` в Git. Он уже исключён через `.gitignore`. Запустите бота:

```powershell
python .\bot.py
```

При пустых настройках бот покажет, какие имена переменных заполнить, не раскрывая их значения. Для работы с VK он должен оставаться запущенным. Остановить — `Ctrl+C`.

## Проверки

Локальные проверки логики каталога, меню и команд запускаются без токена и подключения к VK:

```powershell
python -m unittest -v
```

Также можно проверить JSON отдельно:

```powershell
python -m json.tool .\services.json
```

Реальный диалог нужен, чтобы подтвердить доставку `message_new`, отображение клавиатуры и ответов в VK, а также работу сообщества с фактически выданным ключом и его разрешениями.
