# Бот ВКонтакте: каталог услуг химчистки

Учебный бот для сообщества ВКонтакте. Он работает через **Long Poll API**
с помощью библиотеки **vkbottle** и показывает:

- главное меню по командам «Начать», «Старт», «Меню»;
- каталог услуг и карточку каждой услуги (название, описание, цена);
- прайс-лист со всеми услугами;
- контакт менеджера из настроек;
- пошаговое оформление заявки кнопками: услуга, типовой срок и способ связи;
- ввод текста только для другой даты или телефона/email;
- готовое письмо менеджеру, которое пользователь подтверждает в почтовом приложении;
- понятный ответ на непонятные сообщения и возврат в меню.

Цены в файле `catalog.json` демонстрационные. Заявка после подтверждения
открывает подготовленное письмо на контакт менеджера; бот не отправляет письмо
без подтверждения пользователя.

## Что нужно перед началом

1. **Python 3.10 или новее.** Проверить версию:

   ```powershell
   python --version
   ```

   Если команда не найдена, установите Python с сайта python.org и при установке
   поставьте галочку **Add Python to PATH**.

2. **Ключ доступа сообщества и включённый Long Poll.** Как это сделать —
   в разделе «Как получить ключ доступа» ниже.

## Установка и запуск (Windows PowerShell)

### Шаг 0. Откройте PowerShell в папке проекта

Нажмите `Win + X` → «Терминал»/«Windows PowerShell». Затем перейдите в папку
проекта:

```powershell
cd C:\Bots\VK-2
```

### Шаг 1. Включите правильную кодировку (чтобы русский текст был читаемым)

```powershell
chcp 65001
```

### Шаг 2. Создайте виртуальное окружение `.venv`

```powershell
python -m venv .venv
```

### Шаг 3. Активируйте окружение

```powershell
.\.venv\Scripts\Activate.ps1
```

Если PowerShell выдаёт ошибку про запрет выполнения скриптов, разрешите их
для текущего окна и повторите активацию:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

После активации в начале строки появится `(.venv)`.

### Шаг 4. Установите зависимости

```powershell
pip install -r requirements.txt
```

### Шаг 5. Создайте файл настроек `.env`

```powershell
Copy-Item .env.example .env
```

Теперь откройте `.env` и заполните значения (как это сделать — в разделе
«Как открыть и заполнить .env» ниже).

### Шаг 6. Запустите бота

```powershell
python bot.py
```

Если всё настроено верно, появится сообщение «Бот запущен и ожидает сообщения».
Откройте сообщество ВКонтакте и напишите боту «Начать».

Остановить бота: нажмите `Ctrl + C` в окне PowerShell.

## Как открыть и заполнить .env

1. Файл `.env` лежит в папке `C:\Bots\VK-2` рядом с `bot.py`.
2. Откройте его обычным «Блокнотом»:

   ```powershell
   notepad .env
   ```

3. Заполните две строки. Пробелы и кавычки ставить не нужно:

   ```text
   VK_TOKEN=ваш_ключ_доступа_сообщества
   MANAGER_CONTACT=+7 900 000-00-00
   ```

   - `VK_TOKEN` — **обязателен**. Без него бот не запустится и покажет понятную ошибку.
   - `MANAGER_CONTACT` — необязателен. Можно оставить пустым: бот запустится,
     а кнопка «Связаться с менеджером» ответит «Контакт менеджера пока не указан».

4. Сохраните файл (`Ctrl + S`) и закройте Блокнот.

> Не отправляйте файл `.env` и ключ другим людям и не вставляйте их в переписку.
> Файл `.env` уже добавлен в `.gitignore`, поэтому не попадёт в git.

## Как получить ключ доступа

1. Откройте сообщество ВКонтакте → **Управление**.
2. Раздел **Настройки** → **Работа с API**.
3. Нажмите **Создать ключ** и в списке прав выберите
   **«Сообщения сообщества»** (в API это право называется `messages`).
   Больше прав не требуется.
4. Скопируйте готовый ключ (длинная строка) в `VK_TOKEN` в файле `.env`.
5. Там же, во вкладке **Long Poll API**:
   - включите **Long Poll API**;
   - в разделе **Типы событий** отметьте **«Входящее сообщение»** (`message_new`).

> Для этой реализации нужен именно **Long Poll**. Настройку **Callback API**
> включать не нужно.

Используемые события: `message_new`. Используемое право ключа: `messages`
(«Доступ к сообщениям сообщества»).

## Проверка проекта

Запустить локальные тесты:

```powershell
python -m pytest
```

Тесты **не подключаются к ВКонтакте** и **не используют настоящий ключ**.
Они проверяют:

- каталог `catalog.json` (состав услуг, обязательные поля, ошибки в файле);
- открытие главного меню командами «Начать», «начать», «НАЧАТЬ», «Старт», «Меню»;
- разделы «Услуги», «Прайс-лист», «Связаться с менеджером»;
- карточку каждой услуги (название, описание, цена);
- ответ на неизвестное сообщение и возврат в меню;
- кнопки обычной (не inline) клавиатуры;
- что `.env` и `.venv` скрыты от git, а `.env.example` содержит пустые значения.

### Что проверяется только в реальном диалоге с ботом ВКонтакте

- приём сообщений через Long Poll (работоспособность ключа и включённый Long Poll);
- отображение клавиатуры и переключение кнопок между разделами;
- первое приветствие для нового пользователя;
- задержки и ограничения реального API ВКонтакте.

## Частые вопросы

- **«Не найден VK_TOKEN…»** — файл `.env` не создан или строка `VK_TOKEN=`
  пустая. Выполните `Copy-Item .env.example .env` и впишите ключ.
- **В консоли «кракозябры» вместо русского текста** — выполните `chcp 65001`
  перед запуском `python bot.py`.
- **Бот не отвечает** — проверьте, что в сообществе включён Long Poll API
  и отмечено событие «Входящее сообщение», а ключ создан с правом
  «Сообщения сообщества».
